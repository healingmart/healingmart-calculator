https://github.com/healingmart/healingmart-calculator

중요
1. ZIP을 PC에서 압축 해제합니다.
2. 압축을 푼 폴더 안의 파일과 폴더를 모두 선택합니다.
3. 기존 저장소 루트에서 Add file → Upload files로 업로드합니다.
4. 저장소 최상단에 index.html, demo.html, dist, scripts, test가 바로 보여야 합니다.
5. ZIP 파일 자체를 올리면 안 됩니다.

이번에 반드시 함께 올라가야 하는 신규 파일
- dist/catalog/hm-calculators-manifest.v1.js
- dist/catalog/hm-calculators-search.v1.js
- dist/js/hm-calculator-catalog-loader.v1.js
- scripts/build-public-catalog.js
- scripts/registry-utils.js
- test/public-catalog-contract.v1.js
- test/catalog-loader-contract.v1.js
- test/catalog-growth-simulation.v1.js
- CATALOG_INTEGRATION_GUIDE.md

덮어쓰기 동작
- 같은 경로의 파일은 새 파일로 교체됩니다.
- GitHub Upload files는 새 ZIP에 없는 과거 파일을 자동 삭제하지 않습니다.
- DELETE_OLD_FILES_v6.1.2.txt의 구버전 파일은 별도로 삭제합니다.
